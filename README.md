Platinum Road — the best offline guide and tracker for all 55 Grand Theft Auto VI trophies on PS5. Every trophy with its official name, description and grade, a guide in our own words that cites its sources, a 5-phase roadmap to the platinum, 9 flagged missable trophies, and a checklist whose progress saves in the browser (localStorage) with export/import — plus filters (story, missable, collectibles, activities, strangers, crime, misc), a spoiler-safe mode that hides unrevealed story trophies, and paper/night themes. Static files only: no build step, no network requests, works with the network off.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
# hand it in: MAKEFUN_OUTPUT_DIR=out node main.ts
```
